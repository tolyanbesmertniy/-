Рябов Анатолий, Сягов Иван, Маслов Максим

Название приложения: Хакатон Хаб

Суть приложения: Агрегатор студенческих мероприятий, который помогает не пропустить интересные лекции, митапы, спортивные турниры и хакатоны.

Описание приложения: Приложение работает как афиша. На главном экране представлен список предстоящих событий в хронологическом порядке. Каждое событие имеет карточку с описанием, датой, временем, местом проведения и организатором. Если студент хочет пойти, он нажимает кнопку «Записаться», и событие добавляется в его личный список на вкладке «Мои регистрации». Чтобы студенты не забывали о событиях, приложение за день и за час до начала отправляет локальные уведомления. Также предусмотрена возможность отменить регистрацию, если планы изменились. Приложение интегрировано с общим расписанием, чтобы не регистрировать студентов на мероприятия, совпадающие с парами.
